# Licensing and media ingestion policy

- Review the license for each repository and individual asset before use.
- Record source URL, exact commit/release, license, creator, attribution, retrieval date, and modifications.
- Confirm commercial advertising use, modification, redistribution, attribution, and share-alike conditions.
- yt-dlp may only retrieve user-owned or expressly licensed assets where download and reuse are permitted by the source terms and applicable law.
- Never bypass DRM, authentication, paywalls, or access controls.
- Do not store client-confidential media in this repository unless the client has explicitly approved that storage. GitHub Issues and repository contents may be visible to collaborators; use access-controlled storage for client-sensitive files.
- FFmpeg build licensing depends on the build configuration; preserve its license notices and use a known Ubuntu package build unless a different build is reviewed.
